# Emulsion product context

## Register

product

## Users

People making technical diagrams and illustrations for decks, documentation, and blog
posts. The founder's own diagram workflow is the initial use case. People need to revise
an existing picture, keep the good parts, and find earlier versions.

## Product Purpose

An image studio whose value is the layer around the model: structured prompts, candidate
ranking, reliable region corrections, history, styles, and visible costs. The correction
workflow must accept images made outside Emulsion too.

## Brand Personality

Modern, minimal, polished. Clear task-oriented language and visible processing feedback.
This records the existing README and the user's August 2026 design decisions.

## Anti-references

The user rejected generic AI-looking layouts, an exclusively dark interface, native select
menus, and awkward chat keyboard behavior. Preserve the established Radix controls and
light, system, and dark choices rather than inventing another visual direction.

## Design Principles

- Keep creating and revising in the same conversation.
- Make progress, cost, lineage, and edit scope understandable.
- Reuse the existing component vocabulary.
- Preserve the source image and make every revision a new version.
- Explain limitations precisely, especially the expanded boundary of a region edit.

## Accessibility & Inclusion

Follow the existing keyboard focus styles, labelled controls, reduced-motion support,
and contrast target of at least 4.5:1 for text in both themes. Keep the composer usable
on narrow screens and provide a file button alongside drag-and-drop.
